# Tekniskt redigerings- och exportexempel

Tre bilder skapade genom browserproven. Innehållet är syntetiska testdata.
roundtrip.html kan öppnas lokalt och återimporteras i Slide Fable. Den innehåller
en avsiktlig exempelanteckning för sekretessprovet. PDF/PPTX har ingen talaranteckning.
Objekten överlappar avsiktligt i stressbilden; det är inget layoutförslag.
Exportrapporter beskriver rasterfall. Bildernas ZIP innehåller PNG, inte browser-skärmbilder.
Läs docs/release-review.md för den ännu inte godkända samlade acceptansen.
